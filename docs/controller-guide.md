# 手柄按键说明（ES4All / EmuELEC）

手柄按键在本固件里分**三层**处理，各层的判断依据不同——搞清楚这三层，就不会再被「A/B/X/Y 到底谁是谁」绕晕。

| 层 | 场景 | 判断依据 | 一句话 |
|---|---|---|---|
| 第一层 | **ES4All 界面**（A=确认、B=返回…） | **按键印刷** | 按你手柄印的字母走 |
| 第二层 | **RA / 独立模拟器 热键**（退出、存档…） | **按键印刷标签** | 约定俗成，按标签认 |
| 第三层 | **游戏内操作** | **按键位置** | 按几何位置对齐，跟熟悉感走 |

---

## 第一层：ES4All 界面 —— 基于「按键印刷」

界面上会显示「A 确认 / B 返回」这类提示，所以这一层**跟着你手柄印的字母**走才不会别扭。

市面手柄的 A/B/X/Y 印刷主要有**两种布局**，本固件用一个极简的侦测精灵搞定：**按提示按一下 A、再按一下 X**，就能自动判断你是哪种，并把界面确认/返回、以及后面两层的对齐规则一次配好。

![两种布局侦测](img/layout-detect.svg)

- **按 A 在「南」（下）** → Xbox 式
- **按 A 在「东」（右）** → 任天堂式
- 按 X 在「西」/「北」再细分 X/Y 布局

> 侦测结果写入 `InvertButtons` / `InvertGameButtons` / `InvertXYButtons` 三个设置，供后面两层使用。手动想改，进 **手柄和蓝牙设置 → 手柄按键映射 / 游戏内互换 A·B、X·Y**。

---

## 第二层：RA / 独立模拟器 热键 —— 基于「按键印刷标签」

这些组合键早已广为人知，**按标签认**（按印着 X 的那颗）即可，RA 与独立模拟器**都适用**：

| 组合键 | 功能 |
|---|---|
| **SELECT + START** | 退出游戏 |
| **SELECT + R1**（右肩键） | 保存即时存档 |
| **SELECT + L1**（左肩键） | 读取即时存档 |
| **SELECT + X** | 呼出菜单 |
| **SELECT + Y** | 切换 FPS 帧率显示 |

说明：
- **热键绑定在「印刷标签」上**（`SELECT + 印着 X 的那颗` = 菜单），不是几何位置。单支手柄下完全正常；只有在 Xbox↔任天堂 两种手柄间换用时，同一组合键的物理位置才会不同。
- **`SELECT` 只是约定俗成**的呼出键，并非强制，可自行改。
- **部分独立模拟器不支持「切换 FPS」热键**（模拟器本身没这个功能），其余四个热键通用。

---

## 第三层：游戏内操作 —— 基于「按键位置」

进游戏后**绝对按位置（熟悉感）**走：找出各主机原厂手柄的按键几何布局，把物理位置对齐过去。这样「按下方键 = 触发下方那颗」，跟真机手感一致。

以 **PSP** 为例，符号固定在几何位置：**✕-南、○-东、□-西、△-北**。

![PSP 位置对齐](img/layout-psp.svg)

这一层对**全部 15 个常用平台**自动按各自原厂布局映射，无需手动逐一设置：

`apple2` · `nes` · `snes` · `genesis` · `gba` · `gbc` · `pcengine` · `n64` · `psx` · `saturn` · `dreamcast` · `psp` · `mame` · `fbneo` · `pc`

> 实现上：RA 平台由 `setsettings.sh` 依 `InvertGameButtons/InvertXYButtons` 动态生成 per-core remap（**自动从核心 `.info` 的 `corename` 推导**，任何核心都生效）；PSP/DC 等独立模拟器由各自的 `set_*_joy.sh` 套用同源规则。
